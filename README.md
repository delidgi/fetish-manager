# ST-Fetish-Manager

Расширение для управления фетишами персонажей в SillyTavern.

## Возможности

- 🔥 **40+ фетишей** в 6 категориях
- 🎚️ **Интенсивность** — низкая/средняя/высокая
- 🎲 **Шанс срабатывания** — от 10% до 100%
- 📱 **Мобильная версия** с мини-кнопкой
- 💾 **Сохранение настроек** между сессиями
- 🤍 **Возможность добавления своего фетиша**

## Установка

https://github.com/delidgi/fetish-manager

## Категории фетишей

| Категория | Примеры |
|-----------|---------|
| ⛓️ Власть и контроль | БДСМ, Доминирование, Бондаж, Приручение |
| 🧠 Психологические | Унижение, Похвала, Папочка, Развращение |
| 👀 Риск и публичность | Публичный секс, Вуайеризм, На грани |
| 💋 Телесные | Анал, Шлепки, Грудь, Шрамы |
| ✨ Сенсорные | Завязанные глаза, Латекс, Игрушки |
| 💕 Отношения | Aftercare, Dirty talk, Групповой секс |

## Как работает

1. Выбери фетиши кликом по кнопкам
2. Настрой интенсивность и шанс
3. Расширение автоматически добавляет промпт в чат

### Логика срабатывания

```
[FETISH LOGIC]
- Roll 1d100 перед каждым ответом
- Если roll <= шанс: интегрировать фетиш естественно
- Если roll > шанс: vanilla сцена с лёгкими намёками
- Никогда не форсировать в неподходящий контекст
```

## Удаление фетишей из пресета

После установки расширения можно удалить все фетиш-тоглы из пресета:
- Все промпты с `fetish_` в setvar
- Категорию `|🫦ФЕТИШИ`
- Промпт "Логика Фетишей"

Расширение полностью заменяет эту функциональность.
